SISTEM SURVEI TERPADU | PEMBARUAN FORM UDARA 21 OKTOBER 2026

1. Ekstrak semua file ZIP ke dalam satu folder.
2. Buka index.html melalui Chrome atau Edge.
3. Pada Beranda, pilih Pengambilan Sampel Udara Ambien atau Pengambilan Sampel Air.

YANG DIPERBARUI
- udara.html diganti dengan isi persis dari file index(2).html pengguna, dengan satu penambahan di luar formulir: tombol Beranda.
- Struktur isi form udara 5 halaman, sketsa, penyimpanan, sinkronisasi, dan cetak mengikuti versi index(2).html.
- index.html (Beranda) dan air.html (form air 2 halaman) dipertahankan dari sistem terpadu sebelumnya.
- Penyimpanan otomatis dan multi-project menggunakan key yang sama seperti versi udara sebelumnya sehingga data tersimpan pada origin/browser yang sama tetap kompatibel.

PENTING
- Data browser disimpan di penyimpanan lokal (localStorage). Jika dipindah ke folder atau alamat berbeda, browser dapat menganggapnya sebagai asal baru; gunakan Ekspor/Impor JSON untuk migrasi dan cadangan.
- Saat cetak: pilih A4, ukuran 100% dan aktifkan background graphics (jika perlu); margin None/minimum karena formulir sudah ditata A4.
- Tidak perlu akses internet atau instal server.
